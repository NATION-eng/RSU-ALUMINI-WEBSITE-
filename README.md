> **Theme:** *"Rooted to Rise: Honouring our Heritage, Igniting our Future"* (Isaiah 61:3)  
> **Celebration Dates:** November 13th – 15th, 2026  
> **Grand Jubilee Sabbath:** Saturday, November 14th, 2026  
> **Venue:** Rivers State University (RSU), Port Harcourt, Nigeria

## 📖 Overview

This repository contains the official, high-performance web portal for the **Adventist Students' Fellowship (RSU Chapter) 45th Jubilee Celebration & Alumni Homecoming (1981–2026)**.

### ✨ Features & Deliverables

1. **Hero & Grand Jubilee Countdown:**
   * Live countdown clock synchronized to Saturday, November 14, 2026 (Grand Jubilee Sabbath).
   * Scriptural and theme showcase (*Rooted to Rise*).
2. **Interactive 45-Year Milestone Journey (1981–2026):**
   * Chronological milestones across 4 distinct eras (Pioneers, Growth, Consolidation, and Digital Horizon).
3. **Official Homecoming Schedule:**
   * 3-Day breakdown with timezone converter (WAT, GMT, EST, CST).
4. **"I Will Be There" DP Generator:**
   * 100% client-side HTML5 canvas image composite engine.
   * Custom user portrait upload, pan/zoom alignment, name, graduation set, and cohort badge styling.
   * High-resolution 1200×1200px PNG export with instant confetti celebration.
5. **Dual-Purpose Alumni Census & RSVP System:**
   * Permanent directory capture for 1981–2026 graduating sets.
   * Event headcount tracking for Physical vs. Virtual participation, dietary, accommodation, and compendium tributes.
6. **Media Hub & Live Broadcast Center:**
   * High-definition livestream room and official audio jingle preview.
7. **Global Diaspora Hub:**
   * Dedicated channels for alumni across the UK, USA, Canada, Europe, and the Middle East.

## 🛠️ Technology Stack

* **Frontend:** React 18 + Vite
* **Styling & Design System:** Tailwind CSS (Custom Heritage Emerald, Jubilee Gold, Mint Glow, and Warm Linen Cream palette)
* **Icons:** Lucide React
* **Effects:** Canvas-Confetti
* **Canvas Processing:** Native 2D Canvas API (zero-server compute, safe cross-browser geometry)

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* npm (v9+)

### Installation
```bash
# Clone the repository
git clone https://github.com/NATION-eng/RSU-ALUMINI-WEBSITE-.git

# Navigate to project folder
cd RSU-ALUMINI-WEBSITE-

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Building for Production
```bash
npm run build
```
